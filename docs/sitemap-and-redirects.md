## Locales

English is the canonical root: `www.thetransedge.com/give`, not `/en/give`. That
keeps every existing inbound link and every printed URL working.

The other six are prefixed: `/ar/…`, `/zh/…`, `/hi/…`, `/sw/…`, `/ja/…`, `/ko/…`.

At launch the prefixed locales carry the visitor-essential set only:
plan your visit, what to expect, find us, EdgeKids, get in touch, and service
times on all of them.

`hreflang` advertises only locales with a reviewed translation. An unreviewed
locale routes, renders English and is `noindex`, so it is never advertised as an
alternate that does not exist yet.

## Redirects

`src/data/redirects.mjs` is the source. `public/_redirects` is generated by
`npm run build` and CI fails if the two are out of step, so a hand edit to the
generated file cannot survive.

The generator refuses a rule that points a path at itself, refuses a duplicate
source, and refuses to exceed Cloudflare's limits of 2100 rules and 100 dynamic
rules. It found four self-referencing rules on its first run.

Current state: **86 rules, 9 dynamic, 77 static.**

### Covered

| Family | Examples | Destination |
|---|---|---|
| Wix member area | `/account`, `/members`, `/my-account` | Connect |
| Legacy sign-in | `/login`, `/signin`, `/portal` | Connect sign-in |
| Elvanto | `/elvanto/*`, `/church/*`, `/roster` | Connect |
| Wix pages | `/about`, `/visit`, `/sermons`, `/contact` | The new IA |
| Wix commerce | `/plans-pricing`, `/product-page/*`, `/service-page/*` | Nearest real destination |
| Wix blog | `/post/*` | `/edgedin` |
| Wix events | `/event-details/*` | `/events` |

### Not yet covered, and this is a launch blocker

**The live Wix route list has not been enumerated.** The map covers Wix's route
conventions and the families above. That is not the same as the actual list of
pages on the current site.

Egress to `www.thetransedge.com` was blocked from the build environment, so the
sitemap could not be read.

### How to finish it

Ten minutes with access to the current site.

1. Fetch the Wix sitemap. Wix splits it, so take the index and each child:

   ```bash
   curl -s https://www.thetransedge.com/sitemap.xml
   curl -s https://www.thetransedge.com/pages-sitemap.xml
   curl -s https://www.thetransedge.com/blog-posts-sitemap.xml
   ```

2. Extract the paths:

   ```bash
   curl -s https://www.thetransedge.com/pages-sitemap.xml \
     | grep -o '<loc>[^<]*</loc>' \
     | sed 's|</\?loc>||g' \
     | sed 's|https://www.thetransedge.com||' \
     | sort -u > wix-routes.txt
   ```

3. Add anything not already matched to `src/data/redirects.mjs`.
4. Replace the two wildcard rules on `/post/*` and `/event-details/*` with
   per-item mappings, so a blog post lands on its own replacement rather than on
   a section index.
5. Also collect, from outside the sitemap:
   - links printed in past bulletins
   - QR codes still in circulation
   - anything in Google Search Console's coverage report
   - Elvanto deep links members still have bookmarked

6. Verify after deploy:

   ```bash
   while read -r route; do
     code=$(curl -s -o /dev/null -w '%{http_code}' -I "https://www.thetransedge.com$route")
     [ "$code" = "301" ] || echo "$route -> $code"
   done < wix-routes.txt
   ```

   Anything that is not a 301 is a route that has not been mapped.

The definition of done requires every Wix, portal and Elvanto route to redirect,
with no orphan pages and no broken links. Until step 6 comes back clean, that is
not met.

## Generated sitemaps

`@astrojs/sitemap` writes `sitemap-index.xml` at build, per locale, excluding
`/admin` and `/brand`.

## Cutover

1. Point DNS at Cloudflare, keeping the Wix site live on its own hostname while
   the redirects are verified.
2. Deploy, run the verification loop above, fix what fails.
3. Switch the apex and `www` records.
4. Submit the sitemap in Search Console and watch coverage for two weeks. A rise
   in "not found" is a route the map missed.
