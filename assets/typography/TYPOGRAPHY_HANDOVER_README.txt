THE TRANSFORMATION EDGE — WEB TYPOGRAPHY HANDOVER v1.0

FINAL DIRECTION
Inter Display is the only display face. Inter is used for navigation, body,
buttons, labels and legal/access information. The serif treatment shown in the
website concept is not adopted: although attractive, it would create a second
and competing masterbrand voice.

ACCENT

no more than approximately 10% of a typographic composition. Never colour an
entire heading.

IMPLEMENTATION RULES
1. Website headings and copy must remain real HTML text for accessibility,
   responsiveness and search visibility. The outlined SVGs are visual masters.
2. Desktop display type: 82px/88px, weight 700, tracking -3.1px.
3. Minimum navigation: 14px. Minimum ordinary body text: 16px.
4. 12px microtype is permitted only for supporting labels, never essential
   instructions, access conditions, safeguarding, privacy, complaints or giving.
5. Preserve sentence case. Avoid all-caps headings and excessive tracking.
6. Use Deep Slate #303847 on Porcelain #F6F5F2. Ember is an accent, not a field.
7. The wordmark must use the supplied outlined master; do not retype it.

NOTE TO DESIGNER
The angled rule is a supporting expression of the A2 threshold. It should align
to the layout grid or frame image/video; it must not become decorative clutter.
